## Causes and fixes (Round R03)

1. TOC read-back: the R02 calibration used the Chapter line, which Word reads right (1.00 in); only TOC 2 lines read 0.50 in short. Two rounds show Range.Information(5) is not a reliable instrument here. Fix: the Word-side horizontal TOC checks are removed; scripts/measure_pdf.py measures them on the returned PDF. Seal top and pitch stay on the Word side.
2. Runner window: fixed pixel positions. ISE is DPI-aware, so text scaled and positions did not. Fix: one-column TableLayoutPanel, DPI auto-scale, each control on its own row.
3. Label log: Word reads LabelName back empty; the line now says the label id matches.
4. Accessibility statement (PFM decision 13 Nov): new optional `meta.accessibilityLink` {text, url}; the renderer links the text in place; the validator fails if the text is not in the statement or the url is not https (F-020). Sample uses "XXX-XXX SharePoint" and a fake example.sharepoint.com address.
